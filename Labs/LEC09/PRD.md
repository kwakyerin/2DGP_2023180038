# LEC09 애니메이션 뷰어 PRD

- 상태: 구현 완료
- 대상 위치: `Labs/LEC09`
- 입력 자료: `sonic-sprite.png` (`399×525` 픽셀)

## 1. 제품 개요

LEC09 실습용 단일 파일 Python 프로그램이다. pico2d로 Sonic 스프라이트 시트에 포함된 애니메이션을 화면에 표시하고, 정해진 순서로 재생을 반복한다. 사용자는 프로그램을 실행해 별도 조작 없이 각 동작의 애니메이션을 확인할 수 있다.

## 2. 목표

- 스프라이트 시트에 정의된 모든 애니메이션 동작을 재생한다.
- 동작별 반복 횟수와 동작 사이 대기 시간을 일관되게 적용한다.
- 화면에서 확인하기 쉬운 크기로 이미지를 확대해 표시한다.
- 구현을 작은 단계로 나누어 진행하고, 의미 있는 변경을 최소 20개 이상의 커밋으로 남긴다.

## 3. 개발 제약 및 범위

### 포함 범위

- 구현 언어: Python
- 그래픽 라이브러리: pico2d
- 프로그램 구성: Python 단일 파일
- 에셋: `Labs/LEC09` 폴더에 포함된 Sonic 스프라이트 시트
- 재생 방식: 자동 재생 및 무한 반복

### 초기 범위에서 제외

- 키보드·마우스를 통한 동작 선택이나 재생 제어
- 애니메이션 편집, 스프라이트 시트 수정, 에셋 가져오기 기능
- 별도의 설정 파일이나 다중 모듈 구조

## 4. 사용자 시나리오

1. 사용자가 LEC09 애니메이션 뷰어를 실행한다.
2. 프로그램이 같은 폴더의 스프라이트 시트를 불러온다.
3. 화면에 확대된 캐릭터 애니메이션이 자동으로 재생된다.
4. 각 동작이 5회 재생된 뒤 1초 대기하고 다음 동작으로 넘어간다.
5. 마지막 동작까지 재생하면 처음 동작부터 같은 순서로 다시 재생한다.

## 5. 기능 요구사항

| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-01 | 프로그램은 `Labs/LEC09/sonic-sprite.png`를 불러와야 한다. | 필수 |
| FR-02 | 스프라이트 시트에 포함된 모든 애니메이션 동작을 재생해야 한다. | 필수 |
| FR-03 | 각 동작은 해당 애니메이션 전체를 5회 반복 재생해야 한다. | 필수 |
| FR-04 | 동작의 5회 재생이 끝난 뒤 다음 동작을 시작하기 전 1초 대기해야 한다. | 필수 |
| FR-05 | 마지막 동작 다음에는 처음 동작으로 돌아가 전체 재생을 무한 반복해야 한다. | 필수 |
| FR-06 | 캐릭터는 원본보다 크게 표시되어 화면에서 식별하기 쉬워야 한다. | 필수 |
| FR-07 | 프로그램 종료 전까지 프레임 갱신과 화면 표시가 계속 이루어져야 한다. | 필수 |
| FR-08 | 이동이 포함된 동작은 시간에 따라 화면의 가로 위치가 바뀌어야 한다. 화면 가장자리에 닿으면 방향을 반전해 창 안에서 계속 이동한다. | 필수 |

## 6. 재생 규칙

- 애니메이션은 시트에서 확인되는 동작 단위로 구분한다.
- 한 동작의 프레임을 순서대로 재생하는 전체 과정을 1회로 계산한다.
- 각 동작을 총 5회 재생한 뒤 1초를 기다리고 다음 동작으로 이동한다.
- 마지막 동작 후에도 1초 대기 규칙을 적용한 다음 처음 동작부터 재생한다.
- 재생 중 별도 입력이 없어도 계속 진행한다.
- 이동 동작은 프레임 시간과 동작별 속도를 이용해 캐릭터의 화면상 위치를 갱신한다.
- 이동 동작 중 1200×800 창의 좌우 경계에 닿으면 방향을 바꾸며, 캐릭터가 창 밖으로 잘리지 않게 한다.
- 제자리 동작과 동작 사이 1초 대기 중에는 위치를 갱신하지 않는다.

## 7. 화면 및 표시 요구사항

- 기본 창 크기는 약 `1200×800` 픽셀로 한다.
- 캐릭터가 창 안에서 잘 보이도록 스프라이트를 확대한다.
- 확대 과정에서 캐릭터가 창 밖으로 잘리지 않도록 배치한다.
- 이동 동작의 좌우 이동 범위는 캐릭터 표시 폭을 고려해 창 안쪽으로 제한한다.
- 원본 비율을 유지해 캐릭터가 찌그러지지 않게 한다.
- 확대 배율과 배치는 실제 에셋의 프레임 크기를 확인한 뒤 정한다.
